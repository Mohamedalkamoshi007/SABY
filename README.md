# SABY
يهدف المشروع إلى تطوير منظومة ذكية منخفضة الاستهلاك للطاقة، تراقب الأصوات التنفسية للرضيع وتكتشف الأنماط الصوتية غير الطبيعية بالاعتماد على نموذج تصنيف قابل للقياس. وتنبّه المنظومة مقدمي الرعاية عبر لوحة التحكم عند الحاجة، وتوثّق الأحداث المكتشفة وما يرتبط بها من ملاحظات، وتتيح للمدير عرض جميع بيانات النظام وإدارتها.
